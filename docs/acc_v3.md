# v3 多视角自检（4 个内置世界 × 32 机位）

> 工具：`node tools/multiview.mjs --glb-list reports/v3_list.txt --plan v3 --views 32`
> 采集：960×600、dpr1、hw 光栅、每机位稳定 300ms、`?glb=<world.glb>&instant=1`
> 原始数据：`reports/mv3.json`，截图：`shots/mv3/`

## 一、机位套餐（`--plan v3`，本轮新增）

v2 那套 32 机位**全部朝前**（16 个位置 × 2 个 ±25° 偏航），对 v3 等于漏掉一半世界 ——
v3 的视锥外是扩散生成的地形/地物/360° 穹顶，"转身"才是主要观感风险。所以新套餐按
"站在重建区域里走动、转身"来设计，四组各 8 个（4 个位置 × 2 个朝向）：

| 组 | 偏航 | 测什么 |
|---|---|---|
| F 前方 | ±20° | 照片保真度与视差 |
| S 侧向 | ±80° | 薄壳边缘、视锥外的侧向拼接 |
| B 背后 | 162°~180° | 扩散地形、地物、天空穹顶 |
| U 抬/俯 | 0 / 180，俯仰 ±0.55 | 穹顶顶部与脚下地面 |

判据沿用项目口径：**取最差机位**（单个机位的严重缺陷不被其他视角摊薄）。

## 三、这轮自检抓出的两个真问题（已修）

### 1. coast：视锥外地形盖住照片下半屏（void 18.4% → 1.6%）

**现象**：side/back 机位 16~18% 的画面是背景色，正面机位中央也有 12% 空洞。

**根因**：只按"方位半径"挖洞不够 —— 照片的足迹不是凸的，同一方位上不同仰角的
地面半径差几十倍。coast 有 48% 是天空，远景地形在照片的方位范围内从 r=15m 就开始铺，
直接压在照片下半屏上。

**修法**（`terrain.conform_to_photo`）：两类情形分开处理 ——
* 落在**非天空**像素上的顶点：沿该像素射线推到 `z_near×1.06`（投影不变，原点视角
  看不见它，侧移时它正好贴着照片壳下沿，不留洞），并把颜色换成**它背后那个照片
  像素**的颜色（否则侧移露出一块与照片不接的平板）；
* 落在**天空**像素上的顶点：整片剔掉（那个方向本来就不该有地形）。

### 2. alpine：穹顶与地形之间夹出一条空带（void 8.2% → 1.6%）

**现象**：上一版把地形铺到 600m 后，B 圈（背后）中央出现 14% 空洞。

**根因**：600m 处的地平线比真地平线低 0.16°，而天空穹顶从 lat=0° 起铺 → 中间夹出
一条 0.16° 的空带，转身就是一道 void。

**修法**：穹顶纬度从 **-8°** 起铺，与地形外缘重叠。穹顶在 920m、地形 ≤600m，
深度测试保证地形永远在前。

## 四、desert 仍未通过：诊断与已否决的修法

**现象**：back/up 机位里照片内容只剩画面顶部一条，下面 2/3 是一片**灰紫色平板**，
中间还有一圈穹顶的圆形边界。

**诊断**：
1. desert 的视锥外地形**几乎没有起伏**。高度场来自"扩散全景 → 8 视角深度"，
   而沙漠全景的地面本来就平；再加上近场（<30m）被强制压到 y=0（为了让玩家脚下
   与视锥内同高），外面读起来就是一块平板。
2. 穹顶（920m）与平板（≤600m）在画面中部形成一条**硬边界**，看起来像"洞口"。
   指标把它记成 void，人眼读作"空"。

**已否决的修法**（数字留档，避免重踩）：
把地形铺到 900m（想让它接到穹顶下沿）→ 600m 以外的高度场是插值外推的，
一铺就大面积陷下去：`lowVoid 15.8% → 64.8%`，`voidFrac 7.9% → 39.8%`。已回退。

**下一步（按性价比）**：
1. 视锥外的地形起伏改为"从全景图的**地平线高度**反推"（现在的做法是把深度点直接
   落成高度场，沙漠这种平地上几乎没有信号）；
2. 或者对"画面大部分是天空/平地"的照片（`sky_frac > 0.45` 且高度场方差很小）
   直接走"照片墙 + 360 天空"形态，而不是硬铺地形 —— 这需要一条按图选择形态的路由。

## 五、这些指标看不见的东西

自检只覆盖"空底/塌黑/拉丝/清晰度"。以下是本轮的目检结论，指标里没有对应项：

* 山脊有 1px 的过渡带（断崖格四角混着天空像素）；
* 侧视里树是**圆锥**，不是照片级的植被；
* 全景是扩散生成的，地平线高度与照片未必对齐，接缝处有高度台阶；
* 正面机位里照片内容与外部地形的**亮度**略有差异（贴图 vs 顶点色）。

## 六、复现

```bash
python -m http.server 8199 --bind 127.0.0.1          # 或 start_v3.bat
node tools/multiview.mjs --base http://127.0.0.1:8199 \
  --glb-list reports/v3_list.txt --plan v3 --views 32 \
  --out shots/mv3 --json reports/mv3.json
```

`reports/v3_list.txt` 四行：`assets/world-v3-alpine.glb` 与
`out/v3/worlds/{desert,coast,winter}/world.glb`。

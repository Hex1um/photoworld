## 逐图结论

1. **24 张里没有一张触发点云**（断崖占比全部 < 1%）。这是预期的：点云是为"网格必然被剪碎"
   的密集枝叶准备的，普通风景照用网格更好（点云侧面是点雾）。
2. **指标最差的三张都不是几何问题，而是素材本身信息量低**：
   - `e1349c17`（日落云海）：底部是云谷，没有地面几何 → lowVoid 0.140；画面本身是对的。
   - `3b8b0a97`（蓝调雾山）：整幅低对比雾气，`centerLapVar` 0.8 是场景属性，不是缺陷。
   - `51518c74`（背光雪山，原图 5472×2976）：渲染成"深色剪影"，山体细节在贴图降采样
     （2048 上限）+ 曝光对齐后被压掉了 —— **这是真缺陷，下一步应让贴图上限随原图分辨率提升**。
3. **`10e77a47`（蓝天草地水洼）的地面糊成色板**：照片中景本身是平滑草地，
   但渲染里能看到平铺感。试过把地面压平容差 0.30 → 0.14，几何与贴图完全不变（地面拟合本来就准），
   所以不是压平的问题；更可能是程序化地面在照片视锥外的接缝。**未修，记为已知问题**。

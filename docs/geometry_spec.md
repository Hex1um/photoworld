# 几何口径（唯一来源）

本文件是**标定 / 角度 / 远场压缩**的唯一口径。任何一处实现与本文不符，都算 bug，
不要靠"两边各调一下让它对上"的方式修 —— v1.21.2 的 `r0` 只修 Python、js 没修，
就是这么分叉出来的。

## 1. 像素 → 视线（角度）

针孔相机，像素网格在**切向**均匀：

```
u = (col + 0.5) / W            # 0..1
v = (row + 0.5) / H
dx = (u - 0.5) * 2 * tan(hfov/2)
dy = (0.5 - v) * 2 * tan(vfov/2)
d  = normalize(dx, dy, 1)      # 相机系，z 向前
```

- **禁止**用 `sin(Δv·vfov)` 近似 dy 的角度（js 旧实现，vfov=60° 时偏差 3~4%）。
- 需要"射线的 y 分量"时：`dirY = dy / hypot(1, dy)`（中心列，dx=0）。
- 方形像素约束：`tan(vfov/2) = tan(hfov/2) · H / W`。宽度改变（视场延拓）后必须重算 vfov。

## 2. 相对视差 → 距离（标定）

模型：**`z = A · (r + b)^(-p)`**，r 为"越大越近"的相对视差 ∈ (0,1]。

- 归一化**只除 hi**：`r = clip(d / percentile(d, 98), 0, 1)`。
  **不许减 lo** —— 减 lo 会平移视差，破坏 `z ∝ 1/r` 的乘性关系（p 会偏 +50%）。
- 形状 `(p, b)` 由**地面带逐像素拟合**决定：
  地面点满足 `z = eye / (-dirY)`，对 `(r_i, z_i)` 做对数空间最小二乘；
  b 在 `[0, 0.5]` 网格搜索（步长 0.02），取残差 MAD 最小者，再两轮 IRLS 去离群。
- 绝对尺度由**远端锚点**给出：`A = horizon_far · (r_far + b)^p`。
  **`r_far` 必须按视差选**（上空区域视差的 5 分位），**不许**按"贴地平线的行带"选 ——
  俯仰 ≠ 0 时那条行带会落到地面上（实测 +8° 时选到 35m 的地面，A 被放大 42×）。

## 3. 近端饱和（r0）

```
r_near_eff = r_near + b
denom      = (far/A)^(1/p) - 1/r_near_eff
r0         = 1/denom             （denom ≤ 0 时退化为 (A/far)^(1/p)）
a_eff      = A · (1 + r0/r_near_eff)^p
z(r)       = a_eff · (r + b + r0)^(-p),  clip 到 [near, far]
```

`a_eff` 不是冗余项：它保证 `z(r_near) = A·r_near_eff^(-p)`（近端锚点不被 r0 破坏）。
**删除 `a_eff` 会让近端整体偏近 r0 那么多。**

Python 侧唯一实现：`pipeline/geom.apply_calibration()`。测试与生产都调它，不要各写一遍。

## 4. 俯仰角

`pitch` 由**地面带拟合残差**反解（`geom.estimate_pitch`）：最小化 `z = A(r+b)^-p`
对地面带的 MAD，粗搜 ±12°/1° → 细搜 ±1°/0.1°。

- js 侧的地平线行号约定：`v_horizon = 0.5 - tan(pitch) / (2·tan_v)`（抬头 pitch>0 → 行号变小）。
  **实现时必须用双符号合成用例定号**，符号写反会让整幅俯仰变号。
- 产物：`world.json.camera.pitch_deg` / `pitch_source`。

## 5. 远场压缩（渲染域，不是距离模型）

`metric()` 给出的 `z` 可到 `horizon_far`（1500m）。渲染层再做一次**单调软压缩**：

```
t_draw = 220 · tanh(metric(d) / 220)
```

- 这是**绘制域**的压缩，目的是把 0..1500m 映射进渲染器调好的 0..220m 世界
  （断崖判据 edgeRatio、竖幕阈值 60m、远层 220m 都按这个量级设定）。
- **验收口径**：js 与 pipeline 的一致性比的是 **`metric()` 的值**，不是 `t_draw`。
  改 `t_draw` 不影响距离模型；改 `metric()` 必须两侧同步。
- 实测警告：直接把 `t_draw` 换成 `metric()`（去掉 tanh）会让山体整片消失
  （alpine 只剩一条地平线）—— 因为远场 t 涨到 1800m 后，`tMax/tMin > edgeRatio`
  把绝大多数四边形判成断崖丢掉。别再试"一步统一"。

## 6. 验收阈值

| 项 | 阈值 | 说明 |
|---|---|---|
| 视场延拓角度误差 | < 1% | `tools/verify_extend.py` |
| 标定 p（合成 `z=c/r` 输入） | 0.95 ≤ p ≤ 1.05 | 同上 |
| 近场距离误差中位 | < 5% | 同上 |
| 俯仰反解误差（±8° 输入） | < 1° | 同上 |
| 法线单位长度 | ∈ [0.99, 1.01] | `test_regression.py::test_normals` |
| 交叉门覆盖率比 | ≥ 0.90 | `eval.report` |
| 非锚带尺度偏差 | < 20% | `eval.ground_band_check` |

"尺度门失败率"这类**统计口径**必须附条件（例如"p>2 **且** 近场误差>10%"），
不能单独设阈值 —— 相对深度模型的固有压缩会让它永远卡住。

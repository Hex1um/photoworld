## 自回归 rollout

`forward 5` 连续 5 帧：**画面塌成近乎全黑**，只剩一条微弱地平线。

这是典型的自回归发散：单步预测在学"复制上一帧"（+0.81dB 的增益本身就说明了这点），
一旦把自己的输出喂回去，误差按帧累积，迅速收敛到条件均值（暗色）。

## 根因判断

1. **训练量严重不足**：1500 步 × batch 2 = 3000 样本，仅 0.65 个 epoch
2. **动作信号太弱**：数据里 turn 约 2.9°/帧、forward 0.12 单位，只通过 adaLN 注入，
   注意力层无法直接"读"动作 → 模型倾向忽略动作、退化成复制
3. **CFG 无条件分支不对**：现在用 `action * 0`（等于 idle 动作），
   应该是独立学习的无条件嵌入
4. **历史帧噪声增强**（50%）在短训练里让它更依赖"抄上一帧"

## 下一步（按性价比排序）

1. 训练到 8000~15000 步（8G 卡约 3~4 小时），先看 rollout 是否还在塌
2. 动作改为**独立 token 插入目标帧前**（spec 原始设计），并把动作幅度标准化到 unit 方差
3. CFG 用可学习的 null 嵌入替换 `action*0`
4. 环境当前**无法后台长跑**（会话结束进程被回收），需要：写 resume 支持 + 每 250 步存档（已具备存档）

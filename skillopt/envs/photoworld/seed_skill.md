# PHOTOWORLD 烘焙调参技能（种子版本）

你负责**为一组照片选择重建参数**，让"照片 → 3D 世界"的渲染尽量少出现
空洞、拉丝、露空白。你的输出就是下面那段 yaml；改它，别改别的。

## 判据（唯一标准）

每张图会被烘焙、渲染 4 个机位，并计算四项客观指标。**越小越好**：

| 指标 | 含义 | 阈值 |
|---|---|---|
| `stripe` | 拉丝强度（纹理被拉成条） | ≤ 2.0 |
| `streakBlobs` | **拉丝块数**（竖条/拉花的连通域个数） | ≤ 200 |
| `innerVoid` | 中景空洞占比 | ≤ 0.06 |
| `voidFrac` | 露空白占比 | ≤ 0.10 |
| `voidBlobs` | **空白块数**（碎成多少块） | ≤ 260 |
| `voidBlobMax` | **单块空白最大占比** | ≤ 0.22 |
| `voidRunMax` | **最长横向空段**（按宽度归一） | ≤ 0.50 |
| `lowVoid` | 画面脚下空洞占比 | ≤ 0.08 |

全过 = `hard=1`。分数 `soft` 按超阈值程度扣减，其中 `stripe` 与 `streakBlobs` 权重最高
（拉丝最影响观感），`voidRunMax` 次之（贯穿式的一条缝比碎点更难受）。

**块数为什么重要**：同样 3% 的空白，散成几百个小点观感远好过一块大洞；
同理一条贯穿竖条比满屏细纹更难看。所以只看占比会漏掉"形态"这一层。

## 已知经验（从实际排查看出来的）

* `far_split` 是"近景/远景"的分界线（米）。太小 → 中景被当远景、无视差；
  太大 → 远景参与视差，边缘拉丝。风景照 90~120 比较稳。
* `ground_radius` 决定程序化地面铺多远。太小 → 转身看到空白；太大 → 三角面暴涨、
  烘焙变慢。
* `seg_edge_tau` 是地物分割的灵敏度。灯柱/树枝这类细物需要更灵敏（0.08~0.12），
  过大会把建筑切成碎片 —— 直接表现是 `streakBlobs` 上升。
* 若 `voidRunMax` 偏高（有一条贯穿画面的空段），通常是分层/剪面的交界问题，
  调 `far_split` 比调别的更有效。
* `skirt_cap` 控制剪影处"厚度"。太大会在近处变成一块醒目色板。
* `card_flatten` 把近处细物压成卡片。**只对它命中的物体有益**，放宽判据会伤到别的区域。

## 你要改的东西

```yaml
params:
  far_split: 100
  ground_radius: 400
  seg_edge_tau: 0.10
  skirt_cap: 1.2
  card_flatten: true
```

## 输出要求

* 只输出一段 yaml 代码块，里面只有 `params:` 一项；
* 只允许出现上面列过的键；
* 数值要在下列范围内：`far_split` 60~160、`ground_radius` 150~600、
  `seg_edge_tau` 0.05~0.20、`skirt_cap` 0.4~3.0；
* 不要解释，不要加别的段落。
